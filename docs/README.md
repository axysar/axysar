# GitHub Pages Setup

1. Open repo `axysar/axysar` on GitHub.
2. Go to `Settings` -> `Pages`.
3. Under `Build and deployment`, set `Source` to `Deploy from a branch`.
4. Select branch `main` and folder `/docs`.
5. Save and wait for deployment.

Site URL:
- `https://axysar.github.io/axysar/`

## Optional Assets

If you want a custom banner and avatar in your profile README or Pages site, add:
- `/assets/banner.jpg`
- `/assets/avatar.jpg`

After adding files:
- Uncomment the banner line in root `README.md`.
- Add an `<img>` block in `docs/index.html` hero section if desired.
